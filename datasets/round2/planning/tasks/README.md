# 四人任务包发送说明

每位队友发送两份：`00_共同规则与命令.md` + 其个人 `A/B/C/D_任务清单.md`。
每份个人清单最后的“可直接转发的消息”可复制到聊天框，附件交付细节以正文为准。

顺序：先冻结公开设计规则与范围；A 做 510、B 做 340 开发候选，D 独立做受限 150 测试候选，B 同时整理三条件；C 受限核查全部 1,000 条并只对 850 开发条目划分训练/验证，D 独立检查；共同冻结后 D 试产/C 复核；再由 A/B/C 出 P1/P2/P3 开发谱；最后 A 冻结模型、D 测试/B 复核、D 评分。

本包尚未执行任何生产、训练、权限配置或 GitHub 消息发送。命令中的本机路径、种子和冻结文件是需填写的输入，不是现成可运行批次。
