# 第三轮公共准备区（A维护）

当前只有方案和填写模板，没有已冻结配置、可执行生产清单或已验收数据。以[第三轮方案](../planning/第三轮数据构建方案.md)为准，B/C/D不各自另造最终主表。

出谱前由A补齐并发布实际文件和SHA-256：

1. 范围、32目标元素、四类设计及四人目标/干扰对/族ID分配；完整候选、原始底板、换算/补偿账目与历史来源。
2. 从第二轮A封存输入逐字节继承P1/P2/P3并验证源哈希；D1～D6、T1～T3完整配置、结构校验、物理一致性与预注册窗口预算。参数提案不是已验证配置。
3. 历史近邻与母族连通组、全局用途和每族条件映射；同族/同物理样品不能跨用途。旧谱曝光状态保留。
4. 开发profile白名单、T封存与禁入记录；模型训练/字典代码的候选数量适配在训练前完成。
5. 全部子种子、生成器0.2.1/核心0.2.0及依赖/源码身份、真实运行命令；不猜路径和数值。
6. 每人15配方×6=90谱试片记录、全量自检、窗口损失、实际耗时/容量和最终数量冻结。

正式索引、冻结清单和曝光记录由A维护；成员只提交本人候选与实际报告。模板在[templates](templates/README.md)，必须复制到实际交付位置、填入证据后再评审；模板中的null和pending不是通过。

本次不附生成器新版本、修改过的物理核心、完整D/T配置或训练模型。它们尚未完成第三轮适配，不能把目录存在当作功能已实现。方案中的本地baseline路径仅用于溯源，模型文件未随本提交上传。
