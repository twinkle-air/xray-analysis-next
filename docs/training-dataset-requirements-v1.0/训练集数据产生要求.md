# X射线模拟训练集数据产生要求

独立 FP 生成器｜执行与验收规范 v1.0

适用交付软件：fp_competition 0.2.1；物理模型版本：0.2.0。

本规范将既定的“100配方×3谱”流程检查要求、2026-10-17审查整改意见，以及后续扩大训练库所需的覆盖设计合并为可执行说明。审查对象的原始数据与原审查记录保留历史身份；新软件生成的数据必须另建版本。

**核心原则：每条谱可追溯、整批可复算、标签与输入隔离、工程验证与科学准确度分开。**

本规范不是实测方法认证，不构成“95%的独立实测结果含量相对误差≤5%”的达标证明。模拟标签指实际参与计算的组成；生成参数指模型假设，不能自动解释为客户未知仪器的真实条件。

阅读顺序：第2—4页确定范围与标签；第5—8页检查条件与谱；第9—14页按命令生成、校验与复算；第15—19页处理划分、限制、整改与交付。

交付对象：负责生成数据、审查数据、训练数值模型和构建智能体分析流程的团队成员。各成员应使用同一冻结版本的本规范与软件，不能各自解释“全部通过”。

# 01 适用范围、角色与状态

**必须**表示本轮交付或验收不可缺少；**建议**表示正式库设计应采用的做法；**候选方案**不构成已经确认的数量或科学性能门槛。

| 阶段 | 目的与验收边界 |
| --- | --- |
| A：小批量流程样例 | 已约定100种独立采用配方，每种3条谱，共300条。检查结构、完整性、参数记录、可复现及说明一致性。 |
| B：正式合成训练库 | 先冻结样品范围、目标元素、含量层级、响应配置和划分，再按覆盖矩阵生成。数据量由学习曲线与分层表现决定。 |
| C：独立实测验证 | 用未参与建库/校正/调参的样品及可信组成评价真实能力；设备、批次和基体的留出须单独设计。 |

本轮不得把5万条候选预算、所有矿石/土壤覆盖或真实盲测准确度追加为A阶段既定验收条件。未能读取的分享页面内容不作为新增依据。

| 角色 | 应完成的事项 |
| --- | --- |
| 生成负责人 | 冻结配方、条件和种子；执行生成；保存原始输入与软件快照。 |
| 数据审查者 | 在包外输出QC、完整物理重算和问题闭环记录；明确抽查/全量及运行环境。 |
| 训练负责人 | 只向预测模型提供允许的输入；标签用于训练或独立评分，不混入盲测推理输入。 |
| 项目负责人 | 确认研究范围、覆盖表和正式库预算；确认已通过、待补齐、未验证事项。 |

status=complete仅表示程序生成完成。软件写入acceptance_status=pending_independent_validation；不得把这个字段改成“全部验收通过”替代独立证据。

# 02 先设计覆盖，再决定规模

正式训练集不能只重复默认配置。当前地质配方以SiO2补足，源为假定Ag靶和49kV，几何/探测器配置也有固定假设；这不代表已经覆盖任意矿石、土壤或未知仪器。

| 覆盖维度 | 每批计划必须说明 |
| --- | --- |
| 基体 | 例如合金、硅酸盐、富铁氧化物分别建表；不把随机氧化物混合物声称为真实矿物总体分布。 |
| 含量 | 缺失、低含量、次量与主量；范围必须结合样品体系，不让全部目标只在同一痕量区间。 |
| 元素组合 | 单独、少量共存、多元素共存；专门安排As/Pb、S/Pb等干扰组合及不同含量比。 |
| 激发/响应 | 源、管压、滤片、能窗、刻度、分辨率、效率、几何、空气路径的合理配置。 |
| 信号质量 | 不同计数水平、弱峰、截窗与有效扰动；未建模效应不得用随意加噪声冒充。 |
| 留出 | 未见配方族、基体或响应配置；记录谁用于训练、谁仅用于最终评价。 |

A阶段保持100×3=300。B阶段候选预算可取5000种有效配方×5份冻结响应配置×2次计数抽样=50000谱；该数字只是工程预算，不是统计充分性或达标结论。

当前--replicates在每次重复时重新抽取jitter并派生子种子，不能直接把replicates=10解释为“5个相同响应各2次噪声”。若需5×2结构，可使用同一5000配方全集，分别用5份固定profile、关闭jitter、replicates=2生成5批；每批10000谱，恰好达到单批上限。

多批保持同一成分全集和split_seed只是现有同成分划分一致的必要执行方式；集合改变、增加配方、基体留出或近邻隔离时，需要另行统一冻结全库划分。先小规模测运行时间和磁盘需求，不一次盲目生成全部预算。

# 03 配方、单位与标签

默认32个候选目标为：Na、Mg、Al、Si、P、S、Cl、K、Ca、Ti、V、Cr、Mn、Fe、Co、Ni、Cu、Zn、As、Se、Rb、Sr、Y、Zr、Nb、Mo、Cd、Sn、Sb、Ba、W、Pb。候选目标列表不是32元素实测定量认证。

| 字段/内容 | 必须遵守的规则 |
| --- | --- |
| id | 非空、批内唯一，稳定关联配方。谱ID由程序生成，与客户名称隔离。 |
| composition_percent | 实际输入的元素质量百分数；保留完整基体，不只保留目标元素。 |
| compounds_percent | 化合物质量百分数，先按原子质量分数转元素；不能直接用作元素含量标签。 |
| trace_ppm | mg/kg；10000ppm=1%质量分数。不得将100ppm写成100%或0.1%。 |
| original_percent | 换算/闭合策略处理前的元素组成，原值保留。 |
| used_percent | 实际进入物理模型的组成；训练、合成评分以此为准。 |
| targets_percent | 固定目标列，缺失的合成组分补精确零；单位为元素质量百分数。 |
| provenance | 配方来源、原始化合物/ppm、换算、闭合与身份边界。 |

采用strict时元素总和必须在1e-6个百分点容差内为100%；不满足就拒绝。normalize_explicit必须主动指定，同时保存原始总和及采用值，不能仍以未归一化值给模拟结果评分。

Fe2O3T是总Fe按Fe2O3报出的约定；按化学计量分配O是模型假设，不证明实物铁价态或氧含量。H/C/N/O可影响基体吸收与散射，本版不产生其低于1keV的荧光，不能把它们列为直接荧光定量目标。

精确零表示合成配方没有加入该元素，不等于真实样品未检出或不存在。来源未给值、低于限值和真实未检出必须与零分开。公开参考组成重建保留原来源身份，不称实测谱或完整认证真值。Als/Alt等非元素字段须明确映射，不能静默相加。

# 04 激发、时间与样品条件

下列字段来自本版Profile。每条truth和full必须保存实际采用的完整profile，不能只存扰动范围或配置名称。所有数值都要有单位；缺少实测来源时明确标为模型假设。

| 字段组 | 字段、单位与解释 |
| --- | --- |
| 激发源 | target：靶元素；voltage_kV：管压kV；tube_line_fraction：假定靶线比例。 |
| 管流 | current_uA、reference_current_uA：μA；模型以二者比值缩放曝光。 |
| 时间 | live_time_s：活时间s。没有实时间、死时间模型时不能补写实测值或宣称已校正。 |
| 入射通量 | incident_photons_s：源侧滤片后、所设外部入射空气路径之前的光子率；绝对值未校准。 |
| 源侧吸收 | tube_be_um：Be管窗μm；filter_Al_um：Al滤片μm。滤片在当前源模型中主要改变归一化谱形。 |
| 样品厚度 | mass_thickness_g_cm2：质量厚度g/cm²；不等于质量g。其换算应有密度/厚度或几何依据。 |
| 几何 | detector_distance_cm、detector_area_cm2；incident_angle_deg、exit_angle_deg、scatter_angle_deg。 |
| 空气 | incident_air_path_cm、exit_air_path_cm：cm；air_density_g_cm3：g/cm³，干空气近似。 |
| 积分 | source_step_keV：入射积分步长keV；secondary_layers：质量深度层数。 |

源能量网格从1keV延伸到管压，与探测器输出能窗分开。输入管压高于输出窗上限不代表高能入射光被漏算。吸收边在源积分分段中处理；原子截面与源谱近似的科学不确定性仍需独立评价。

不得把管流、光子率、时间与任意归一化系数重复相乘。空气路径=0只表示模型没有施加该外部空气路径，不能据此声明用户设备处于真空。样品水分、粒度、表面粗糙度和矿物不均匀性当前未单独建模。

# 05 探测器、刻度与模型状态

| 字段组 | 字段、单位与规则 |
| --- | --- |
| 输出轴 | channels：64—8192个通道；gain_keV_channel：keV/道；zero_keV：第0通道中心能量keV。 |
| 分辨率 | noise_fwhm_eV：电子噪声FWHM/eV；fano_factor：无量纲；pair_creation_eV：成对能量eV。 |
| 效率近似 | detector_si_um：Si厚度μm；detector_be_um：Be窗口μm；有效面积和距离参与几何响应。 |
| 逃逸峰 | escape_fraction：有效比例；从主信号扣除后移位，非实际晶体结构的反演结果。 |
| 人工本底 | background_counts_channel：每道期望计数。它在响应记账后另加，不计入截窗前物理信号。 |
| 物理开关 | secondary、scatter必须是真布尔值，控制二次荧光和散射计算；关闭时保留限制说明。 |
| 校准状态 | calibration_status必须为assumed_unverified；本版拒绝用配置字段自行宣称已硬件标定。 |
| 软件/物理版本 | 交付软件0.2.1；物理求解模块0.2.0。用源码哈希区分身份，不只看版本字符串。 |

每个通道中心为E_i=zero+gain×i，i从0至channels−1。左边界为zero−gain/2，右边界为zero+gain×(channels−1/2)。必须区分通道中心范围与积分窗边界。

扰动刻度后，每条谱有自己的能窗；不能把默认配置的一个固定窗口用于整批描述。软件在truth/full中写energy_window，并在manifest/自动README中汇总各中心与边界的最小/最大值。

element_support只检查激发、窗口和假定响应。其“结构支持”不是检出、可识别或可定量结论；1%严重衰减提示阈值是启发式标记。Na/Mg对空气与低能响应敏感，在气氛和窗口未验证前不得承诺可靠定量。

# 06 盲输入与完整结果的数据契约

盲输入只允许五个字段。不要向盲输入加入能量轴、配方、标样编号、profile、随机种子、来源说明或能直接暴露标签的信息。

| blind_inputs字段 | 类型与约束 |
| --- | --- |
| axis | 固定字符串channel。 |
| signal_unit | 固定字符串counts，表示本程序生成的合成计数。 |
| synthetic | 必须为true。 |
| x | 长度channels；整数序列0…channels−1。 |
| counts | 同长度非负整数；不是计数率，也不是归一化信号。 |

| full_results主要字段 | 必须保存的内容 |
| --- | --- |
| record_id、schema、版本 | 唯一谱ID、格式、软件版本、physical_model_version与xraylib版本。 |
| channel、energy_keV | 通道与模型真值能量轴；能量轴只作内部真值。 |
| counts、expected_counts | 加噪声后的计数与加噪声前期望值。 |
| components_expected_counts | 六类物理/人工分量，逐通道与期望谱一致。 |
| profile、composition | 全部实际条件；原始/采用组成、单位与闭合记录。 |
| lines | 元素、跃迁名称、能量、一次/二次发射贡献；发射贡献不是已探测计数。 |
| losses与窗口 | detected_signal_before_window_counts、outside_window_counts、energy_window。 |
| provenance与状态 | source_provenance、element_support、warnings、seed、poisson、synthetic=true、hardware_validated=false。 |

JSON中不允许NaN/Infinity；科学计数法溢出为无穷也必须拒绝。所有谱/分量长度一致且数值有限。full和truth的组成、profile、种子、来源与warnings应一致；full额外包含基体元素的support记录是允许的范围差异。

# 07 六类分量与窗口损失的正确解释

| 分量名称 | 期望计数的含义 |
| --- | --- |
| primary | 一次荧光经效率、出射空气、展宽、逃逸扣除和截窗后的计数。 |
| secondary | 一代再激发荧光采用同样响应处理后的计数；不是完整高阶荧光求解。 |
| rayleigh | 假定几何下的单次相干散射响应。 |
| compton | 单次非相干散射响应；未精细建模束缚电子轮廓和多次散射。 |
| escape | 从物理主信号扣出再移位的逃逸分量，不是凭空增加的计数。 |
| background | 人工每道期望本底，最后加入；不能当作实测本底或已标定背景。 |

逐通道检查：expected_counts = primary + secondary + rayleigh + compton + escape + background。

窗口账目检查：detected_signal_before_window_counts ≈ sum(expected_counts − background) + sum(outside_window_counts)。这里的“截窗前”已包含探测效率和出射空气的衰减，不是样品发射前或源端光子总数。

源积分覆盖到管压；荧光与离散化散射谱都经过deposit，计算其入窗高斯积分及窗外份额。因此窗外损失不仅是峰尾，也包含线中心或散射能量点完全位于窗外的信号。它不包括效率/空气吸收前被衰减掉的光子，也不包括人工本底。

若报告比例，必须写分母。本版window_loss_fraction定义为sum(outside_window_counts)/detected_signal_before_window_counts，按每条谱计算，再报告整批最小/最大值。分母为0时不计算比例，不以任意常数替代。

浮点账目容差采用rtol=1e−12、atol=1e−8 counts。闭合仅证明实现中的账目自洽，不证明物理近似正确、绝对效率已校准或真实含量准确。禁止继续沿用无脚本支持的“静默损失”比例。

每个新版本使用新的输出目录；拒绝覆盖已有数据集。原审查的300谱和README保持原样，修订结果另存，避免抹去审查证据。

  full_results/S000001.json ...
  truth.jsonl
  manifest.json
  integrity.json
  README_dataset.md
  inputs/samples.json
  inputs/original_samples.json
  inputs/original_profile.json

original_*只在CLI提供了对应文件时复制。GUI/API至少封存实际样本和配置，但不能补造未提供的原始文件或设计命令。源文件可从truth重建时，必须标注“重建件”及来源哈希，不能冒充队友最初生成的原件。

每批包含全部运行源码、QC与重算入口、实际环境锁文件。无需交付虚拟环境二进制目录；安装步骤和Python版本必须明确。外部原子数据通过锁定的xraylib依赖获得，不能遗漏依赖后声称离线即可在任意新电脑运行。

# 09 清单、哈希与证据链

| 位置/字段 | 意义 |
| --- | --- |
| manifest.records[].file | 该条盲输入的相对路径。 |
| blind_input_sha256 | 盲输入文件字节的SHA-256。 |
| sha256 | 兼容旧字段，仍明确等于blind_input_sha256。 |
| full_results | 完整结果相对路径。 |
| full_results_sha256 | 完整结果的独立SHA-256，不能拿盲输入哈希代替。 |
| family、split、id | 组成族、归属与谱ID；须与truth和重新规划结果一致。 |
| source_samples_semantic_sha256 | 样本列表经约定JSON序列化的语义摘要；与原始文件字节哈希不同。 |
| physics_core_sha256 | 本批源码快照core.py的字节摘要。 |
| integrity.json | 覆盖truth、manifest、输入、配置、源码、文档等所有其他封存文件。 |

integrity.json自身排除，避免自引用。不得把文件集合增加/删除后仍称原清单有效。哈希路径使用相对POSIX路径；绝对路径、上级目录跳转和指向包外的链接必须拒绝。

修改后的源码与基准应有差异说明。0.2.1保留core.py、minerals.py、robustness.py的修订前字节，预期摘要见physics_baseline.json；版本与封存/QC代码另存。此基线证明工作区模块保留，不证明此前缺失的队友源码原本是什么。

哈希只证明与记录快照一致，不证明来源真实性或科学准确度。最终ZIP用外部.zip.sha256记录自身摘要，不把ZIP哈希写回已经封存的内部文件形成循环。

# 10 三类种子与重复样本

| 种子/参数 | 实际控制范围 |
| --- | --- |
| design或design-mineral的--seed | 配方抽样；原设计JSON保存seed和范围配置。 |
| batch的--seed | 响应参数扰动和每条谱子种子的派生；扰动字典的顺序影响抽样序列。 |
| batch的--split-seed | 组成族划分；若省略，沿用批次seed以兼容旧行为。 |
| 每条truth/full中的seed | 在给定期望谱下抽取该条Poisson计数。 |
| --replicates | 每个输入配方的重复次数，每次重新抽扰动并派生子种子。 |

同配方3条不是“同seed重放3次”，而是同批次随机过程派生的不同子种子和相应条件。同一配方的期望谱在响应变化时也会变化，不仅是噪声变化。

仅在组成、profile、物理算法和版本固定时，单独改变单谱seed才只改变计数抽样。改变批次seed不能被描述为“仅改变Poisson噪声”；默认情况下还改变划分，显式固定split_seed后才将划分随机源分离。

复现必须保存样本顺序、扰动字段顺序、全部配置、批次种子、划分种子、子种子、闭合策略与目标列表。软件记录NumPy默认位生成器名及实际依赖环境。仅记一个随机种子不够。

固定profile并关闭jitter时，重复谱才共享同一个响应条件；不同噪声重复仍属于同配方组。不能跨集合，也不能将3条噪声重复计为3个独立物理样品。多次生成的S000001编号需要批次命名空间，合库时不能直接覆盖同名文件。

# 12 独立QC：必须全量遍历

使用交付包中的源码快照和实际依赖，不仅查看目录是否存在。执行audit会遍历全部记录，报告写在封存目录外：

```text
python -B <包内快照app.py> audit --dataset <数据集目录> --out <包外qc.json>
```

| 检查组 | 验收条件 |
| --- | --- |
| 文件/清单 | 完整性清单的文件集合及每份哈希匹配；300盲输入、300完整结果、300truth记录一一对应。 |
| 输入隔离 | 盲输入严格五字段，无能量、种子、来源、条件或含量泄漏。 |
| 数组 | 长度与通道数一致；计数非负整数；所有期望谱/分量数值有限非负。 |
| 跨文件 | counts、profile、seed、组成、来源、warnings一致；不存在重复谱ID。 |
| 标签 | 目标列与实际used_percent一致，包含精确零；原始组成按策略复算一致；基体保留。 |
| 分量/损失 | 六分量逐道求和等于期望；截窗前后信号在容差内闭合。 |
| 刻度 | 能量轴与profile相符；中心/边界、每条窗口与整批汇总正确。 |
| 随机过程 | 按记录expected和子种子重放Poisson；按批次recipe重放扰动/子种子/划分。 |
| 版本/分组 | 源码快照核心摘要及物理模块基线一致；同组成族不跨集合。 |

数值标准：组成总和容差1e-6个百分点；数组/计数账目rtol=1e-12、atol=1e-8 counts。计数数组和离散身份字段要求一致，不以浮点容差容忍少一个计数或错一个ID。

QC输出passed仅表示这些工程检查通过，报告明确complete_physics_recalculation=false。QC必须能拒绝人为篡改：改变完整结果、泄漏标签、修改分量、跨文件不一致或路径越界都不应被漏过。重新计算哈希也不能掩盖语义不一致。

# 13 完整物理重算与打包

Poisson重放只使用已有期望谱，不能证明期望谱的物理计算可复现。完整重算必须重新调用core.simulate，从原始组成和实际profile重新计算期望谱、六类分量、谱线、损失与最终计数。

```text
python -B <包内快照app.py> replay --dataset <数据集目录> --out <包外replay.json>
```

默认重算全部记录。--limit N只检查前N条；报告标scope=subset和complete_physics_recalculation=false，不能写“整批完整复现”。QC失败或运行核心摘要不同，重算工具拒绝继续，要求使用交付快照。

同环境要求计数逐道一致，期望谱和各物理量按明示容差比较；报告最大数组绝对差异、错误列表、环境一致性及重算数量。environment.json还记录数值线程环境变量；复现时按记录在进程级设置，不必改系统配置。跨环境数值匹配可报告passed_with_environment_differences，但必须保留差异，不能升级为同环境严格复现。

文件逐字节相同、随机抽样相同、完整数值相同是不同检查。软件不以重新序列化JSON的字节摘要相同代替物理重算；时间、元数据与格式变化也不能被用来掩盖实际数值差异。源码哈希只能核实快照，不能恢复缺失的历史修改源码。

```text
python -B <包内快照app.py> pack --dataset <数据集目录> --out <包外dataset-v2.zip>
```

pack先执行QC，失败则拒绝打包；通过后建立ZIP并做CRC检查，外部写.zip.sha256。pack不自动完成全物理重算，replay报告是单独验收材料。

若重算发现差异，不可直接覆盖旧数据或放宽容差直到通过。先归因于环境、输入、源码、抽样或物理实现，再提交修订版及差异记录。保留原失败报告，重新评审后闭环。

# 14 数据划分与训练信息边界

当前软件按实际采用组成的精确摘要分族，再以划分种子排序，近似70/15/15分配。至少3个组成族时保证三集合有记录；100族×3条的既定小样例通常对应210/45/45条。

| 情况 | 应执行的隔离 |
| --- | --- |
| 同配方不同噪声/响应 | 全部保持同组，避免记住相同标签和近似形状。 |
| 同原谱的平滑/展宽视图 | 保留原谱父ID，不能当独立样本跨组。 |
| 真实样品重复测量 | 按实体样品/制样批次分组，不仅看文件名。 |
| 未见响应/设备 | 整份配置或设备留出，需要单独划分设计；现有随机同组成划分不自动实现。 |
| 未见基体/配方邻域 | 冻结基体或配方族级留出，不能仅比较完全相同的哈希。 |
| 多批合库 | 统一命名空间、全库去重和分组；不同成分全集即使seed相同也可能改变划分。 |

训练期间可关联truth取标签；推理/盲测只读blind_inputs；评分程序单独读truth。full中的真实模拟能量轴、profile、配方来源及无噪声分量属于内部真值，不能暗中作为未知条件任务的输入特征。

组成存在标签与“谱中已检出”分开：正含量也可能受低计数、截窗、重叠和吸收影响而不可辨。不能用模拟配方是否非零直接给实测检出结论。

评价应按元素、浓度、基体和响应分层，包括误报、漏报、无法报告比例与含量误差；不能只给总体R²或谱相似度。独立实测95%/5%目标另需可信实物组成、条件完整的对照和冻结的开发方案。

# 15 已知模型限制与Ba案例

本版计算均匀平板近似、一次荧光、一代再激发、固定观察角单次散射、假定源谱和Si探测器响应。独立原子数据不等于完整仪器数字孪生；增加样本数量不会消除共同的模型误差。

| 某谱线中心在窗外 | 指明元素、线系、能量、窗口和剩余可用信息。 | 整个元素一定无法推断含量。 |
| Ba的K系超窗 | 当前谱缺少该K系信息；检查保留的L系及相关M线记录。 | Ba一定不可定量或一定可定量。 |

| element_support有可用线 | 给定假设下具备激发/记录的结构条件。 | 已达到检出限、已消除重叠或误差≤5%。 |

原300谱审查记录：207条含Ba，Ba K线中心约31.817—37.2609keV，位于本批记录窗外；它们保留窗内Ba L线，完整记录也有M线。该事实仅属于原审查批次，其他配置必须重新统计。

当前未验证真实设备效率/刻度、死时间/堆积、复杂多层、粗糙度、粒度、水分、矿相与多次散射等影响。外部空气当前只施加衰减，不能因此宣称完整建模了空气散射或Ar荧光。不得用任意噪声模拟这些效应后称“已覆盖”。

需要独立模拟器或实测参照检查模型偏差；即使对照一致，也须明确比较对象和范围，不能把对一个样品/条件的结果泛化为所有元素与基体。
