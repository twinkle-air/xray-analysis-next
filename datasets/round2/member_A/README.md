# 第二轮 A 数据：下载后先恢复原文件

当前网络的大文件上传反复超时，因此仓库用 1 MiB 传输分块存放大文件。全部数据都保留，未降低精度或删减谱。

在本目录运行：

```text
python -B restore_transport.py
```

仅使用 Python 标准库，不需要先安装生成器。脚本逐块校验并恢复 30 个原生 ZIP 及其他被分块的文件，拒绝覆盖冲突文件，最终核对原始交付中全部 479 个文件的 SHA-256。恢复后按 [原交付说明](README.original_delivery.md) 解包与使用；原始说明的哈希对应 README.original_delivery.md，其他路径不变。

250 独立配方、P1/P2/P3 各 500，共 1,500 谱，全部自检通过；跨成员去重、全局划分及训练放行仍待完成。不要递归把 transport_parts 当成谱。
