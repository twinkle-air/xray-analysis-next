# 第三轮数据构建方案：补足元素证据与条件泛化

状态：**建议执行版 v1.0，待公共输入与全局登记冻结；尚未开始出谱。** 本文件是第三轮唯一方案入口，不替换第二轮历史方案、原数据或模型。沿用第二轮实际参与的 A/B/C/D 四成员制，A 为项目负责人。

## 1. 这轮解决什么

第二轮最新证据模型 `outputs/model-round2-evidence-20261022/evidence_model.npz` 的 SHA-256 为 `31185fd25766a495e4191a8882240fe10a15791ef861885a1b7bd41f0453bd7e`。已曝光的888条内部回归谱上：零含量误报率3.95%，≥10ppm阈值漏报率24.37%，严格正含量结果中相对误差≤5%的比例36.61%，含量≥1%的对应比例82.01%；低于10ppm的精确定量仍没有改善。

Na、Cu、Zn没有找到同时满足五项开发约束的新分支，仍保留旧路径；它们在这批回归数据上仍分别有97、107、78项零含量误报。Co、Cd、Rb还存在漏报或误报权衡。第三轮应针对这些缺口补数据，而非复制第二轮同一种配方、同三个条件的噪声。

本轮保持32个目标元素、硅酸盐/氧化物和富铁氧化物两大体系，不扩大到任意材料。优先级：

1. Na/Cu/Zn的精确零、低含量、强干扰对照，避免由旧回归估计直接判定存在。
2. Cd/Co/Rb及其他目标的漏报控制，不用提高统一门槛换取低误报。
3. 隐藏刻度、分辨率、曝光和空气路径发生变化时的响应适配。
4. 增加新家族和真正没有参与本轮调参的留出材料。原888条已曝光，不再是新测试集。

这轮是方法开发数据，不预先承诺95%/5%目标。第三轮不是“生成更多数据便自然达标”的验收。

## 3. 配方如何设计

### 3.1 六个关键元素的梯度：360配方

Na、Cu、Zn、Cd、Co、Rb各10个全新底板，其中6个硅酸盐、4个富铁；每底板生成6个水平，包括1个精确零和5个正值区间，共 `6×10×6=360` 配方。每族各水平使用相同的3个测量条件。

| 元素 | 六个浓度水平：元素ppm，而非氧化物ppm |
| --- | --- |
| Cu/Zn/Cd/Co/Rb | 0；[0.5,2)；[2,5)；[5,15)；[15,50)；[50,200] |
| Na | 0；[10,50)；[50,200)；[200,1,000)；[1,000,5,000)；[5,000,30,000] |

正值在各区间内按冻结种子对数抽样，不统一取1/3/10/30/100等固定点。验证/留出族也独立抽连续值，避免模型记住六个标签值。区间是研究设计，不是实验检出限。

Na不用与痕量金属完全相同的浓度范围：需要覆盖其实际主量区，也需要保留弱信号区。每个元素至少3个底板族含长曝光D5，且同族其他条件包含较短曝光，用于观察增加有效计数是否有实际收益；不要把低含量只安排短曝光、高含量只安排长曝光。

**精确零检查实际完整组成。** Na=0时不能残留Na2O或NaCl来源；Cu/Zn等也要查所有化合物/基体来源。最终标签和区间判定以实际参与模拟的元素质量分数为准，`1ppm=0.0001质量百分数`。低于参考方法检出限的真实样品不能因此标为精确零。

### 3.2 八组匹配干扰：200配方

每组5个新底板（3硅酸盐、2富铁），每底板5个配方，共 `8×5×5=200`。以下能量用当前xraylib 4.3.0核对，仅用于确定候选干扰，不证明它们是现有误报的原因，也不证明每个条件下都可测。

| 目标/干扰候选 | 代表谱线及能量keV |
| --- | --- |
| Na / Zn | Na Kα1 1.0410 / Zn Lα1 1.0116 |
| Cu / Ni | Cu Kα1 8.0478 / Ni Kβ1 8.2647，强峰邻近背景案例 |
| Zn / W | Zn Kβ1 9.5720 / W Lβ1 9.6724 |
| Cd / K | Cd Lβ1 3.3165 / K Kα1 3.3138 |
| Co / Fe | Co Kα1 6.9303 / Fe Kβ1 7.0580 |
| Rb / Y | Rb Kβ1 14.9612 / Y Kα1 14.9584 |
| As / Pb | As Kα1 10.5436 / Pb Lα1 10.5512 |
| Ti / Ba | Ti Kα1 4.5109 / Ba Lα1 4.4663 |

五个配方统一为：`(目标0,干扰低)`、`(目标低,干扰低)`、`(目标0,干扰高)`、`(目标低,干扰高)`、`(目标高,干扰高)`。干扰是可移除痕量元素时“低”可为0；Fe、K等已构成基体时不强行归零，低/高取相应材料设计范围内的两档，不能把富铁配方去掉Fe后仍称富铁。

目标/干扰的实际浓度、比例、强弱档位在冻结时列明，不只写“干扰强”。同时记录伴随K/L线、逃逸线与测量能窗的结构支持情况；在某条件下弱到不可观察仍是有效困难案例，不为提高成绩删除。

### 3.3 负例/加标配对：240配方

共120个新底板，每族2配方：目标精确零，以及同底板的目标正值。目标分配为Na40族、Cu30族、Zn20族、Cd10族、Co10族、Rb10族；每个目标的底板保持60/40两基体比例。

负例保留相邻强峰、散射、逃逸峰和连续本底，不把所有干扰都清空。Co负例特别覆盖强Zn及其逃逸峰附近背景，Cu/Zn覆盖Ni/W等干扰情景；具体强弱依据冻结响应支持检查，不能仅凭浓度大小认定峰很强。

加标建议范围：Na 1,000–10,000ppm；Cu/Zn 20–200ppm；Cd/Co/Rb 10–100ppm，按连续区间抽样。它们是设计范围，不是承诺可定量范围。其他关键元素的零/正值状态随机平衡，避免“某个目标为零就意味着所有其他目标都为零”的固定标签捷径。

### 3.4 常规背景：200配方

各族只1个配方；120硅酸盐、80富铁，沿用已有范围文件和独立连续抽样。32目标均保留；痕量零/非零及主量变化跨成员、基体和开发条件分散。适度补Na零状态，但不把它全部集中于某个成员或材料子类。

这200条用于保持一般性，不代表真实客户样本的自然分布。第三轮富集负例/难例后，总体指标必须按情景分层，不能把混合配额下的数字冒充客户现场发生率。

### 3.5 匹配与成分守恒的共同规则

同一底板族必须登记原始基体、变更元素、浓度、化合物换算、补偿/稀释方案及最终实际组成。增加目标质量必然需要补偿或缩放其他质量，因此“同底板”不声称所有其他元素的绝对百分数完全不变。采用明确的基体比例保持或指定平衡组分法，登记非目标元素及O的变化；不得用自动归一化偷偷改变目标实际浓度。

完整基体O等参与模拟，32目标标签不被强制归一到100%。所有方案仍是均匀元素质量近似，不冒充真实矿物相、天然地质分布或真实污染过程。

## 4. 条件覆盖：固定公开开发条件，不自由jitter

原P1/P2/P3逐字节继承第二轮A封存配置。新增条件均由A生成完整profile并登记哈希，成员不能自行猜参数。下面是**参数提案，尚非已验证/已冻结的配置**；需要Profile.validate及小批运行后确认。未列参数继承对应父profile，源谱和全部物理分量重新计算，不对旧计数谱作平移/拉伸冒充新测量。

| 开发条件 | 父条件及建议改动 | 目的 |
| --- | --- | --- |
| P1/P2/P3 | 原封存参数 | 锚点；P3是20kV低电压版本，不用旧规划的其他P3 |
| D1 | P1：gain×0.995 | 刻度斜率小变化 |
| D2 | P1：gain×1.005 | 相反方向刻度变化 |
| D3 | P1：noise_fwhm_eV×1.15 | 分辨率变化，仍用原Fano公式 |
| D4 | P1：zero_keV增加0.03 | 零点变化 |
| D5 | P1：live_time_s×3，即450s | 增加有效计数，与同族较短曝光配对 |
| D6 | P2：exit_air_path_cm增加0.5，即1.0cm | 低能衰减变化；其余保持P2原值 |

开发池共9个条件。训练/验证各族统一分配 `1个原锚点 + 2个不同D条件`，该族所有配方使用同一组合；A集中做均衡分配，条件不与成员、浓度水平或零标签绑定。每条件2个独立子种子。原P2已提供低曝光背景，D5提供对应更高计数；不是单纯增加噪声重复。

留出族基础3条件固定为P1/P2/P3，另外增加T1/T2/T3各2次谱，以便对**同一批新配方**比较已见与未拟合条件：

- T1：围绕P1，在已覆盖gain/zero/noise范围内取一个未用于开发的组合，考察组合泛化。
- T2：围绕P2，预注册轻度外推范围（gain约±1%、zero约±0.04keV、noise最高约×1.25），抽取一个固定组合；保留源电压及探测材料结构，不无依据更换设备类型。
- T3：围绕P3，保留20kV源与材料，组合小刻度/零点/噪声变化和1.5–2倍曝光，考察另一源条件下的变化。

T的具体值和种子须在生产前固定、封存；校验不合规时在出谱前修订设计并留记录。**T不能进入模型训练、校正拟合、响应字典生成或选参；禁止把所有profile目录递归加入字典。** 协调人会为QC接触配置，因此仅称未拟合条件留出，不宣称外部独立保管人盲测。模型若使用了T配置构建候选字典，该组只能降级为“无监督标签的已知响应条件”，不能继续称未见响应。

上述变化是工程压力范围，不是对真实设备误差分布的认定。只变化noise参数并不等于所有能量处FWHM统一缩放；不得添加未实现的拖尾、死时间或堆积模型假装来自冻结物理核心。

## 6. 最小生产流程与前置软件工作

1. **A统一准备**：冻结范围、完整profile及哈希、32目标、四类设计分配、母族、种子和历史登记。收齐四人的候选，合库查组成/亲缘/范围/闭合，再发布外置用途与条件分配。全局未确认前不批量出谱。
2. **成员各做一次试片，再完整生产**：试片只从训练族取1梯度族、1干扰族、1配对族、2常规族，共15配方×6=90谱，计入本人最终1,500基础谱，不额外加量。试片覆盖代表性新增条件和困难低能峰。通过后按领取清单生产完整基础谱及本人留出配方的T挑战。
3. **成员完整自检一次**：每个密封分片用其封存生成器全量audit、全量物理replay和pack，不传--limit、不自由jitter、不修改核心；报告出错不打通过标记。对照族不拆成不完整交付，不向已sealed目录追加。
4. **A只做四项复核并合库**：数量/版本、文件/哈希、实际全量自检证据、全局分组/划分。正常时不重复对全部谱物理重算、不互相循环复核；异常才局部定位或退回。随后发布外置权威索引，开始模型开发，不将成员generator_split拼成研究划分。

前置工具适配必须在出谱前/训练前完成，但**本方案尚未实施它们**：

- 生成器仍建议0.2.1 / 物理核心0.2.0；新增profile、配方计划和只读QC可在外围完成，不修改核心。若发现确需改核心，应另出版本、保留原件并验证，不能混成同版。
- 计划器需支持“每族三个profile集合”和“仅留出族增加T”，支持上述实际记录映射；配方仍用现有id/composition_percent/provenance契约。
- 当前模型训练/拟合工具多处硬编码三个候选。第三轮训练前要参数化候选数量、显式开发profile白名单和测试profile禁入检查，不能直接声称已有模型支持9+3条件。
- 准备梯度/配对关系检查和全局连通组检查。设计基体变化允许按已登记的补偿规则发生，检查该规则，而不是错误要求所有非目标绝对百分数相等。
- 新增profile的结构支持、窗口损失预算和源/探测器参数一致性要预注册。若某条件失败，不事后放宽预算或删掉难元素；出谱前修订设计，已生成失败批次隔离留存。Ba等存在L系时不能仅因K线出窗断言无法推断。

分片按完整族组织，最多约25配方，但允许24/25等实际数量，不为凑25拆开六水平或五控制。全局ID必须带round/member/batch；子种子跨全库查重。

## 8. 验收与后续训练评价

工程验收先确认：1,000个不同实际配方、420设计族的完整变体、每配方基础6谱、留出每配方追加6谱；9开发条件与3留出条件角色正确；32标签正确、含O基体闭合；同族条件匹配、子种子/全局ID无冲突；实际全量自检通过、各文件/源码/配置哈希一致。数量如因整族调整，先以新冻结表为准。A自检不冒充另一人独立复核。

统计评价至少单列：

- 全部严格正值单项≤5%相对误差达标率；全部目标同时达标的谱数。
- 各元素MAE/相对误差、≥1%主量、(0,10)ppm低值、10ppm附近和更高含量分层；零值不算相对误差。
- 精确零误报率、真值≥10ppm而预测<10ppm的阈值漏报率；10ppm不是物理LOD。
- 证据不足/不能报告的比例、覆盖率与错误率；不能通过弃权改变原目标分母。
- 干扰、梯度、负例、常规及材料/条件分层；训练中可家族/类别加权，但不能因此重写验收指标。
- 新家族已见条件与同配方T条件的配对性能差异；按家族做不确定性统计，不把计数重复视为独立实验。
- 固定旧第二轮回归对照以维持可比性，但不拿其曝光成绩冒充新泛化成绩。

模型选参继续使用五项约束：验证误报与阈值漏报不增加、总体与主量达标不下降、MAE不增加。原测试不参与选参。新增难例比例已变化，不能把第三轮混合总分与第二轮36.61%简单混比；应在同一测试集同时比较冻结的新旧模型。

本轮只有约63个名义新留出底板族，分到单个元素或条件后更少；不能据此保证1%级误报上限或真实95%准确率。原“至少95%的独立盲测结果单项含量相对误差≤5%”仍是未实现目标，本方案不缩小适用元素/浓度来宣布达成。

## 9. 实测轨道与容量

建议另行整理12–20份有可信参考值的矿石/土壤或对应基体样品；有资源时让**同一物理样品**跨两台设备并做2–3次重复，保存真实条件和原始谱。实际可用数量待实验资源盘点，**不计入上述6,900谱，也不写成已经取得**。按物理样品分开校准与最终验证，重复/跨设备不能跨用途。

参考值须区分CRM、独立实验室测定和用户指定基准，保留不确定度与方法；程序内置组成或未认证自制标样不能自动升级为认证真值。低于参考方法报告限保留删失信息，不写成精确零。现模型拒绝synthetic=false，不能把实测标成true绕过；真实接口、校准及适用性是后续工作。
