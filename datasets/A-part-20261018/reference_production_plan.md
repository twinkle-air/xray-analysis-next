# XRF 训练集产生方案与三人分工

执行方案 v1.0 · 2026-10-18

适用：独立能谱生成软件 0.2.1，物理模型 0.2.0；配套《X射线模拟训练集数据产生要求 v1.0》。本方案分配的是三位成员的工作，不涉及改造智能体。

**建议 A 由你担任，负责研究范围和最终验收；B 负责条件扩展与批量生产；C 负责全局划分、留出条件和数据归档。** 三人都参加配方设计、生产和交叉复核。正式生产统一使用同一份主配方表，避免各自生成一套互不兼容的数据。

第一轮预算：5,000 种独立配方 × 5 组固定条件 × 2 次独立计数噪声 = 50,000 条合成谱。数量是可调整的资源预算，不代表已经足够训练，也不代表达到真实样品含量误差 5% 的目标。

**当前交付是方案及候选条件配置，尚未生成这 50,000 条数据。** 配方范围、主表和全局划分索引仍需按下文准备并冻结；现有软件没有直接导入全局划分表的功能。

# 1. 三人的责任与交付

| 成员 | 主责与配方设计 | 生产与交叉复核 |
| --- | --- | --- |
| A（建议由你担任） | 总协调；设计硅酸盐/氧化物基体 2,500 配方；合并主表、冻结范围及版本；最终确认覆盖和验收 | 生成 P1、P2，共 20,000 谱；复核 B 的 P3、P4；确认最终汇总 |
| B | 设计富铁氧化物基体 1,500 配方；检查激发、能窗、干扰场景及固定条件实现 | 生成 P3、P4，共 20,000 谱；在开发冻结后复核 C 的 P5 |
| C | 设计铁基合金 1,000 配方；维护亲缘分组、全局划分索引、文件清单和验收汇总；保管 P5 | 冻结后生成 P5，共 10,000 谱；复核 A 的 P1、P2；整理交付归档 |

生产量并非平均分：C 还承担全局索引、留出集保管与汇总。计算负担参考：A 生成 2 万并复算 2 万；B 生成 2 万并复算 1 万；C 生成 1 万并复算 2 万。实际耗时以各机器小批实测为准。

**复核环：A → B 的产物，B → C 的产物，C → A 的产物。** 生产者先自检；另一位成员再检查密封源码、环境、全量 audit 与全量 replay。由同一人运行两个检查不算交叉复核。三人团队交叉复核也不等于外部独立科学认证。

A 冻结研究范围和最终验收；B 对条件与元素支持提出复核意见；C 对泄漏、索引和材料完整性提出复核意见。发现失败项保留失败记录，修复后产生新批次版本，不能直接宣布通过。

# 2. 配方分工与覆盖

| 基体范围 | 负责人与总数 | 互斥情景配额 |
| --- | --- | --- |
| 硅酸盐/氧化物混合体系 | A：2,500 | 常规变化 1,500；稀疏/边界 500；干扰对照 500 |
| 富铁氧化物体系 | B：1,500 | 常规变化 900；稀疏/边界 300；干扰对照 300 |
| 铁基合金体系 | C：1,000 | 常规变化 600；稀疏/边界 200；干扰对照 200 |

以上是三种模拟基体范围，不声称覆盖所有矿石、土壤或材料。每条配方只能占一个配额；总计 3,000 常规 + 1,000 稀疏/边界 + 1,000 干扰 = 5,000。必须按实际采用的完整元素组成去重；去重后不足要补足，不能把不同名字当作独立配方。

常规变化：先写出各体系组分范围、平衡组分、采样分布、来源和适用边界。现成矿物配置不能直接代表富铁矿；B 须另定以铁氧化物为主要平衡组分的范围。合金沿用元素质量分数表达；矿物/土壤代理体系保留氧化物到元素的转换记录。

稀疏/边界：安排适用元素的精确零、低含量、中含量及高含量；连续正值范围不能替代“无此元素”。通过直接样品 JSON/CSV 或配方预处理实现，并复核闭合。每个适用元素争取至少 50 个零和 50 个低含量独立配方，达不到时记录缺口；这只是初始覆盖指标，不是统计功效结论。不得要求铁基体系的必需铁基体为零。

干扰对照：氧化物体系重点安排 As/Pb、S/Pb 等候选重叠情景，合金安排 Cr/Mn、Fe/Co/Ni 等情景；具体谱线由生成结果核实。构造“仅 A、仅 B、两者共存及不同比值”对照。基体效应通过配方与现有 FP 吸收/增强计算体现，不能另加未经验证的经验强度修正。

同一母配方的微扰、对照、近邻及增强谱标记相同 parent_family，统一划分。生成器只自动识别精确组成相同，亲缘关系需三人额外登记。

# 3. 五个条件批次

| 批次与生产人 | 候选条件差异 | 用途 |
| --- | --- | --- |
| P1 · A | 默认参考条件；49 kV，150 s，默认刻度和分辨率 | 开发条件 |
| P2 · A | 30 s，较低假定通量；改变零点、增益、噪声及空气路径 | 开发条件：低计数与响应变化 |
| P3 · B | 20 kV；改变刻度及噪声 | 开发条件：较低激发能量 |
| P4 · B | 49 kV，100 μm Al 滤片，较长空气路径及较大噪声 | 开发条件：低能衰减 |
| P5 · C | 45 kV，50 μm Al；另一组刻度、噪声和空气路径 | 完全留出的模拟配置 |

完整字段以本目录 profiles/P1.json 至 P5.json 为准。均沿用 Ag 靶、Si 探测器及 2,048 通道；它们是合理性待验证的假定配置，不对应已标定的五台真实仪器。P5 是候选配置：C 在接触正式测试结果前冻结其最终文件和哈希；公开候选配置的测试不构成对条件数值的完全保密。

每个批次使用全部 5,000 配方、固定一个 profile、replicates=2，**不传 jitter**。这样两条重复谱才只改变计数噪声。五批各 10,000，达到当前软件单批上限。不要用同一配方 reps=10 加随机扰动冒充固定五条件乘两次噪声。

初步结构检查不证明可定量：P4 的低能元素衰减更强；低电压下重元素也许仅有 L/M 线。32 个目标是候选标签；必须逐谱保留可用谱线、能窗外损失和 element_support。不能因为缺少 Ba K 线就认定 Ba 无法推断，也不能因为存在 L 线就认定可达 5% 误差。

首轮不模拟所有未知仪器：靶材、探测器材料、通道数保持上述范围。水分、颗粒、非均匀性、堆积等未实现机制不能靠更换字段名宣称已覆盖。

# 4. 统一划分与盲测保管

先冻结包含全部 5,000 配方的主表，再按 parent_family 全局分组，目标比例约 70%/15%/15%。近邻家族不可拆分；实际数量允许因分组略有偏差。以下以 3,500/750/750 配方说明预算。

| 权威用途 | 组成与条件 | 谱数示例 |
| --- | --- | --- |
| 训练 | 训练配方 × P1–P4 × 2 | 28,000 |
| 验证与调参 | 验证配方 × P1–P4 × 2 | 6,000 |
| 配方留出测试 | 测试配方 × P1–P4 × 2 | 6,000 |
| 条件留出测试 | 训练/验证配方 × P5 × 2 | 8,500 |
| 配方与条件双留出 | 测试配方 × P5 × 2 | 1,500 |

表中的 8,500 仍应分开报告训练配方 7,000 和验证配方 1,500，不混为“双未知”结果。所有 P5 谱禁止训练和调参；P1–P4 的测试配方同样禁止用于开发。C 保管测试标签、完整结果和正式测试包；B 的 P5 复核在算法与校正方案冻结后进行。

**现有内部 split 不足以表达此划分。** 五批必须使用同一完整主表及统一 split-seed，保证内部精确配方划分一致；但它不自动处理近邻家族或 P5 留出。C 另建 authoritative_index.csv，记录 batch_id、local_id、global_id、formula_id、parent_family、matrix、generator_split、benchmark_split、profile_id、两类文件哈希。下游只按 benchmark_split 读取训练数据。

不得修改已密封 truth/manifest 的 split 来迁就方案。外置索引和全局划分文件单独版本化、记录哈希并交叉核对。正式放大前必须完成该索引及读取规则的小批验证；这项辅助工作尚未由现有生成器提供。

# 5. 按里程碑推进

| 阶段 | 三人的工作与退出条件 | 规模 |
| --- | --- | --- |
| M0 环境和方案冻结 | A 确认范围；B/C 核对配置、锁定依赖与源码；各自实测生成和复算耗时 | 小样，单独目录 |
| M1 新版流程试产 | A 准备 100 配方；B 生成 3 次谱；C 主审，A 复核。完整源码、双哈希、说明、全量 audit/replay 齐全 | 新 300 谱 |
| M2 主表和索引 | 三人提交配方；A 合并去重；C 按家族划分；B 检查覆盖和条件。冻结 5,000 配方、配置和索引规则 | 设计冻结 |
| M3 开发试产 | 只从已冻结的训练/验证配方取约 1,000，P1–P4 各 2 次；评估覆盖、难例、学习曲线与读取泄漏 | 约 8,000 谱 |
| M4 开发条件正式生产 | A 完成 P1/P2，B 完成 P3/P4；测试家族隔离保管；按复核环全量复算 | P1–P4 合计 40,000 |
| M5 留出条件 | 算法、校正及评分口径冻结后，C 生成 P5；B 复核；才开展正式留出测试 | P5 合计 10,000 |
| M6 汇总验收 | C 汇总索引、覆盖、哈希和检查；A 确认通过项/遗留项；B 复查问题闭环 | 50,000 正式谱 |

M1 的新 300 用于闭环试产，不能替历史 300 补证原源码身份。M3 的约 8,000 是开发试产，不在 50,000 之外重复算成新的独立配方；正式批次重生成时按 global_id 去重、保留版本关联。试产不能读取被冻结的测试配方标签或 P5。

若 M3 暴露覆盖不足，先扩展独立配方、干扰对照或配置范围，再决定是否增加数量。只增加同配方泊松重复不能代替新增组成与物理条件。范围变化时重新冻结版本，旧测试结果不能继续当未见测试。

# 6. 生产、复核与目录约定

三人统一取软件 0.2.1 发布包及 SHA256，按包内 requirements-lock.txt 建环境。生产用全局样品主表 master_samples.json；用户输入格式和 provenance 字段遵循当前软件。各人只写自己的批次目录。以下命令在解压后的生成器 app.py 所在目录执行。

```text
python -B app.py batch --samples master_samples.json --profile P1.json --replicates 2 --seed 2026101801 --split-seed 20261018 --targets Na Mg Al Si P S Cl K Ca Ti V Cr Mn Fe Co Ni Cu Zn As Se Rb Sr Y Zr Nb Mo Cd Sn Sb Ba W Pb --out P1_dataset
python -B app.py audit --dataset P1_dataset --out P1_qc.json
python -B app.py replay --dataset P1_dataset --out P1_replay.json
python -B app.py pack --dataset P1_dataset --out P1_dataset.zip
```

P2–P5 替换 profile、输出目录，batch seed 依次 2026101802 至 2026101805。主表和 split seed 保持相同。全量 replay 不加 limit；抽查报告不能代替全量复算。首次运行前记录实际 Python、依赖和工作目录。正式输出目录必须全新，不能覆盖原数据。

每批交付：原始批次目录或完整 ZIP、ZIP 的外部 SHA256、audit 报告、全量 replay 报告、生产者批次记录、复核者签名记录。数据包保留 blind_inputs、truth、full_results、manifest、integrity，以及 inputs 中主表、配置、源码快照、环境和命令。

全局交付：master_samples.json、配方设计原表和范围依据、global_split.csv、authoritative_index.csv、覆盖统计、五批文件清单与哈希、异常台账、验收汇总。C 维护全局文件，A/B 提交后不各自重建另一份“最终版”。

复核失败：注明谱 ID、错误字段、复现环境和原包哈希；交回生产人修复，以新版本重新密封。禁止只重写 QC 结论或绕过失败打包。

# 7. 验收、资源与科学边界

共同工程验收：总数与唯一配方数正确；标签与实际模拟组成一致并闭合；同家族不跨全局集合；P5 无训练入口；blind 输入无条件/标签/种子泄漏；盲输入及完整结果哈希齐全；六分量逐道闭合；记录的窗外损失闭合；全部计数按封存子种子复现；源码和依赖可重建。

覆盖验收：按基体、情景、元素零/正值与含量层、谱线支持、能窗、计数层和 profile 分组报告，明确缺口。高相似度、内部精确重算、分量闭合均不能代替真实分析准确度。

基于此前 12 条参考谱的实际文件大小，单谱盲输入、完整结果与 truth 平均约 1.11 MB；50,000 谱原始记录粗估 51.6 GiB，双份约 103.2 GiB，尚需给归档、索引及大小变化留余量。建议全团队合计预留约 120 GiB 或以上；A/B 各自原始批次约 20.6 GiB，C 约 10.3 GiB。不是要求每人都预留 120 GiB。

完成时间先实测：每台机器记录 100 谱的生成秒/谱、全量 replay 秒/谱及压缩体积，再乘各自生产与复算数量，加 I/O 和问题修复余量。不要未经实测承诺几小时或几天完成。12 条样本的容量估计也不是上限保证。

科学验证单独立项：合成测试只能评估当前模型内泛化；未见 P5 也不是未见真实设备。真实“含量相对误差 ≤5%”需锁定评分口径和可定量范围、用未参与拟合的实测样品和独立参考值核验。零含量不能直接计算相对误差；检出/定量限以下单独统计，覆盖率和拒答率同时报告，不能删掉难例抬高达标率。

本轮不改动生成器物理核心，不虚构未实现的机制，不将旧 300 条数据重新标注为已完成全部科学验收。正式规模以 M1–M3 结果决定；如需扩大，优先补独立配方、关键干扰和真实数据证据。
