# X-ray Analysis Next

通用 X 射线谱分析新版协作开发仓库。仓库保存协作文档、分轮数据交付与第二轮任务说明；尚无新版分析应用程序。

## 开始合作

1. 仓库所有者在 Settings → Collaborators 邀请队友，各自使用自己的账号。
2. 在 Issues 记录需求，指定负责人和验收标准；先共同确认首版范围与输入输出接口。
3. 从最新 main 建立任务分支，每个分支处理一个任务。
4. 完成必要检查后创建 Pull Request，由另一人审查，再合并。
5. main 保持可运行，阶段完成后通过标签和 Release 固定交付版本。

协作细则见 [CONTRIBUTING.md](CONTRIBUTING.md)，新版范围见 [项目简报](docs/PROJECT_BRIEF.md)。

## 分支约定

- main：共同确认的主线。
- feat/<task>：新增功能。
- fix/<task>：修复问题。
- docs/<task>：文档与接口约定。

仓库已启用合并后自动删除任务分支，并只保留 Squash 合并选项。邀请队友、主分支保护和 CI 尚未配置；CI 应在技术栈及测试命令确认后建立。私有仓库的分支保护可用性取决于账号套餐。

## 数据与验证

不提交密钥、虚拟环境、私人实验数据、模型会话和临时结果。公开样例须记录来源与许可。区分输入事实、计算结果、候选推断和未知项；软件回归不替代独立实验验证。

当前仓库为私有开发空间；是否开源及采用何种许可证由协作者在公开前共同确认。
